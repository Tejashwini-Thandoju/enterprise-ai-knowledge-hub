# Enterprise AI Knowledge Hub

## Overview

Enterprise AI Knowledge Hub is a production-style Retrieval-Augmented Generation (RAG) application built from scratch.

This project demonstrates:

- Document ingestion
- Text chunking
- Embeddings
- Vector databases
- Semantic search
- Retrieval-Augmented Generation (RAG)
- FastAPI backend
- Streamlit frontend
- Docker deployment

## Tech Stack

- Python
- FastAPI
- Streamlit
- Hugging Face
- ChromaDB
- OpenAI
- Git
- Docker
